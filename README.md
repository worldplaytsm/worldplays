# WorldPlay

A mobile-first TypeScript/React starter for WorldPlay, a virtual city concept.

## Included
- React + TypeScript + Vite
- A simple procedural 3D city preview using Three.js / React Three Fiber
- Premium Store UI for homes, vehicles, furniture and fashion
- Payment choice: Game Coins or Real Money (demo only)
- Four bottom navigation items: Home, Friends, Feed, Me
- Responsive dark UI with gold accents

## Run locally
```bash
npm install
npm run dev
```

## Important
This is a prototype. Store items and coin balance are demo data stored only in app state. Real payments, authentication, Supabase persistence, multiplayer and production-grade 3D assets are not connected. Do not treat sample prices as real offers.
